# 🦙 Alpaca - AI Chatbot using Groq API

**Alpaca** is a chill, interactive AI chatbot built using **Streamlit** and powered by the **Groq API** (LLaMA 3.2). It allows you to chat in a smooth, conversational interface, save/load chat history, and vibe with a cool assistant.

---

## 🚀 Features

- 🌐 Streamlit web interface with responsive design
- 🧠 LLaMA 3.2 Vision model (Groq API)
- 💬 Persistent local chat history (`chat_history.json`)
- 🛠 Sidebar tools: Save, Load, Clear history
- 🔒 API key handled via config or environment variable
- 🖼️ Lottie animation for aesthetics
- 🪵 Logging and error handling for reliability
